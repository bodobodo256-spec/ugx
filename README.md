# Uganda Sexy Babes (Next.js App)

A modern, high-performance Next.js application for Uganda's premier verified dating and companionship directory.

## 🚀 Features
- **Next.js 15 App Router** (`app/layout.tsx`, `app/page.tsx`, `app/register/page.tsx`)
- **Uganda National Color Theme (Black, Yellow, Red)**:
  - 🇺🇬 Eyebrow badge with live pulse indicator
  - Luxury obsidian-black plaque for "Uganda" with gold border
  - Seductive crimson-red gradient for "Sexy" with glow
  - Luminous 24k gold-yellow gradient for "Babes"
  - Segmented tri-color ribbon bar (Black, Yellow, Red)
- **Call & WhatsApp Action Buttons**:
  - Red background (`#E53E3E`) with white text for phone calls
  - Green background (`#25D366`) with white text for WhatsApp
- **Interactive Directory & Filters**:
  - City filtering across 14 Ugandan towns (Kampala, Entebbe, Jinja, Mbarara, Gulu, etc.)
  - Real-time keyword search
  - VIP Babes & Standard Babes sections
- **Create Profile / Register Page (`/register` & `/create-profile`)**:
  - Live card preview that updates in real-time as the user types
  - Free Standard vs VIP Gold tier selection
  - Client-side portrait photo upload preview
- **18+ Age Verification Modal** (sessionStorage-backed)
- **Responsive Mobile Navigation** with slide-out drawer menu

## 🛠️ How to Run

### Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm start
```
